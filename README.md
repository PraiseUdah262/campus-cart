# CampusCart
## Product Vision
CampusCart is a simple command line program for managing products and orders
It will help users add products, view products, manage stock, and create customer orders.
The aim is to make managing products and orders easier and more organised.

## User Personas
-**Campus Vendor:** A small vendor who wants to keep track of products, stock, and customer orders.
-**Customer:** A student or other customer who wants to place an order and receive clear receipt.
- **Project Administrator:** A person who manages the product information and keeps the system organised.
